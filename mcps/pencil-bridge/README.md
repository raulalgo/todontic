# mcp-pencil-bridge (bundled)

Pencil MCP bridge bundled with Todontic. Lets the Designer skill edit `.pen`
artifact files. Note `.pen` is an *artifact* tool Todontic orchestrates — not the
app's own UI kit, and never rendered in-app (central-command, deferred-viz: D-004).

Stub — implementation lands with PRD-12 / PRD-15.
